   139|## Frameworks & Libraries
   140|
   141|- [Crawlee](https://crawlee.dev/) — Web scraping and browser automation library for Node.js. Built by Apify.
   142|- [Scrapy](https://scrapy.org/) — Fast high-level web crawling framework for Python.
   143|- [Puppeteer](https://pptr.dev/) — Headless Chrome Node.js API by Google.
   144|- [Playwright](https://playwright.dev/) — Cross-browser automation by Microsoft.
   145|- [Selenium](https://www.selenium.dev/) — Browser automation framework, supports multiple languages.
   146|- [Beautiful Soup](https://beautiful-soup-4.readthedocs.io/) — Python library for parsing HTML and XML.
   147|- [Cheerio](https://cheerio.js.org/) — Fast, flexible jQuery-like HTML parser for Node.js.
