# Contributing

Contributions are welcome! Here's how to add a tool to the list:

## Guidelines

1. **Quality over quantity** — Only suggest tools that are actively maintained and useful.
2. **Correct category** — Place tools in the most relevant category.
3. **Format** — Follow the existing format: `[Tool Name](URL) — Short description.`
4. **No duplicates** — Check that the tool isn't already listed.
5. **No spam** — Links should go to the tool itself, not an affiliate or landing page.

## How to Submit

1. Fork this repository
2. Add your tool to the appropriate category
3. Submit a pull request with a brief description of why the tool should be included

## What We're Looking For

- Tools that solve real scraping problems
- Active projects with recent updates
- Good documentation
- Both open-source and commercial tools are welcome
